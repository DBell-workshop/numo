## About Numo

Numo is built around three simple principles:

1. **See it** — large keys (≥ 88pt touch targets), high-contrast type
   that meets WCAG AA, and Dynamic Type support up to AX3.
2. **Tap it** — a calculator state machine you can also drive by
   voice ("five plus three"), in English or Chinese.
3. **Hear it** — every result is read aloud with a clean Apple voice;
   you can disable in Settings if you prefer silence.

On supported devices (iOS 26+ with Apple Intelligence), Numo also
offers an opt-in **AI Boost** mode that understands more natural
speech — "I bought 3 apples at $5" works the same as "3 times 5".
Apple Intelligence runs on-device; nothing leaves your phone.
